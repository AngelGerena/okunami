# Demo portraits

Each file here becomes the sample photo for one niche's demos and gallery previews.
Name the file after the niche id, for example:

- `barber.jpg` for Barbershops
- `grooming.jpg` for Men's Grooming (the men's Farmasi set needs a man's photo)
- `photo.jpg` for Photo and Video
- `stage.jpg` for DJs and Musicians

Any niche without a file keeps the shared `sample-portrait.jpg`.
Use a head-and-shoulders portrait, face centered, at least 800px wide, from a source you have the rights to use.
The niche ids are the `id` values in `src/lib/niches.ts`.
